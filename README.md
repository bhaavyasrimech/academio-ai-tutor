# Academio Ai Tutor

# Agentic AI Application — Academic Project

This repository contains an **Agentic AI system** developed as part of an academic assessment. Built using Google AI Studio and powered by Gemini models, the agent leverages an autonomous reasoning loop (Thought → Action → Observation) and integrated tools to execute multi-step workflows, perform precise computations, and provide structured, transparent responses.

### 🌟 Key Features

- **Autonomous Multi-Step Reasoning:** Breaks down complex user requests into logical execution steps.

- **Tool Integration:** Uses built-in tools (such as code execution and web retrieval) to solve tasks.

- **Structured Outputs:** Returns clean, formatted, and academic-grade answers.
